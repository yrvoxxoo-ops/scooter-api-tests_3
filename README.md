Sprint_7
Автотесты для API сервиса Яндекс Самокат.

# Проверки

# Создание курьера
- успешное создание курьера;
- нельзя создать двух одинаковых курьеров;
- нельзя создать курьера без логина;
- нельзя создать курьера без пароля.

# Логин курьера
- успешный логин курьера;
- ошибка при отсутствии логина;
- ошибка при отсутствии пароля;
- ошибка при неверном логине;
- ошибка при неверном пароле.

# Создание заказа
Проверено создание заказа:
- с цветом BLACK;
- с цветом GREY;
- с двумя цветами BLACK и GREY;
- без указания цвета.
Проверяется наличие поля track в ответе.

# Список заказов
Проверяется получение списка заказов.

# Запуск тестов
Установить зависимости:
pip install -r requirements.txt

Запустить все тесты:
pytest -v
